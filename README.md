Python Weather Information API

Project Description

This project is a Python application that retrieves weather information for a given city using the public Open-Meteo API.

Features

- Search weather information by city name.
- Display city and country.
- Show temperature, humidity, and wind speed.
- Validate empty city names and handle invalid cities.
- Handle connection errors, timeouts, and API errors.

Technologies Used

- Python
- Requests library
- Open-Meteo API

Installation

Install the required library:

python -m pip install -r requirements.txt

How to Run

Run the application:

python app.py

Enter a city name when prompted.
